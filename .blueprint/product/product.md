# Product

**Atlas agents workshop.** Attendees connect, communicate and extend agents by building Atlas,
a map agent: tell it where you are and what you want, it recommends three places, describes
each from checked sources, and draws the walking route. Works anywhere OpenStreetMap has data.

## Outcomes

An agent with tools, an MCP server with a login, a second agent over A2A, a skill, and a map
in front of them.

## Audience

Attendees starting from an empty laptop. The PDF attendee guide in `guide/` assumes nothing.

## Out of scope

Production hardening, rate limiting, and map service guarantees.
